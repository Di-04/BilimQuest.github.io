# BILIM QUEST — рабочая локальная веб-платформа

## Запуск

1. Установите Python 3.10 или новее.
2. Откройте папку `BILIM_QUEST` в терминале.
3. Выполните `python server.py` (Windows: `py server.py`).
4. Откройте `http://localhost:8000`.
5. Для учеников в той же сети Wi-Fi используйте `http://IP-АДРЕС-КОМПЬЮТЕРА:8000` (например, `http://192.168.1.10:8000`). Разрешите порт 8000 в брандмауэре. Для QR-кода используйте именно этот адрес, а не localhost.

## Уже реализовано
- RU/KZ интерфейс; кабинет учителя и игрока.
- Конструктор вопросов: тест с вариантами и короткий открытый ответ.
- 1–5 игровых уровней, критерии и баллы для каждого задания.
- Импорт вопросов из JSON или CSV, экспорт шаблона JSON.
- Импорт TXT/DOCX учебного материала для просмотра/копирования в браузере (не ИИ генерация).
- Комнаты 6-значного PIN, ссылка / QR (генерируется во внешнем QR сервисе при доступе в интернет; PIN всегда работает).
- До 100 игроков в комнате, синхронизация через опрос сервера каждые 2 секунды.
- Реальная передача ответов, оценка /10, XP, таблица лидеров.
- Ручная проверка открытых ответов учителем, рефлексия.
- Хранение состояния комнат в `data/rooms.json`, переживает перезапуск.

## Оценивание
Оценка = заработанные баллы / сумма баллов всех заданий × 10. Баллы за открытый ответ учитываются после проверки учителем. XP — исключительно игровой рейтинг.

## Ограничения и безопасность
Это пилотная версия, предназначенная для контролируемого использования в локальной сети. Ссылку учителя с секретным токеном нельзя передавать учащимся; вход учителя пока без индивидуальных аккаунтов, HTTPS и полноценной авторизации. До размещения в публичном интернете требуется добавить авторизацию, HTTPS, ограничения запросов, управление данными и конфиденциальностью несовершеннолетних, серверную валидацию времени ответов, защиту PIN от перебора и резервные копии. Нет автоматического ИИ анализа файлов и 3D-движка. В качестве production-решения потребуется отдельный деплой с полноценной БД.
